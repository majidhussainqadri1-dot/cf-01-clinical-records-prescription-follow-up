Conditional clinical records, clinician-entered prescription and follow-up system of record for the Sabri Social Homeopathy Platform.

== Description ==

This plugin is disabled by default. It must not process real patient data until all activation gates are accepted. It preserves native ownership of authentication, professional verification, appointments, messages, notifications, shell, assurance and secure media.

== Security ==

Do not report clinical data or secrets in a public issue. Use the private security process described in SECURITY.md.
